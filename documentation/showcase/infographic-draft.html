The eight systems
What each one does, in plain English.
Skills System
Skills System
Markdown files that teach an agent what it knows and when to use it
Skills are short instruction documents — written in plain text, not code — that tell an AI agent what role to play and what it is allowed to do. The system only loads the parts it needs for the current task, so adding more skills never slows things down or blows up costs.
Progressive Disclosure Multi-Skill Agents Skill Amendments & Learnings
Plugin System
Plugin System
Package a skill and its tools into a portable, permission-fenced bundle
A plugin bundles one or more skills and the tools they need into a single, shareable folder — with an operator-level dial that can allow certain tools and deny others outright, with no exceptions, so a third-party plugin can never quietly do more than it was given permission to.
Boundary Governance Injected Mode
Tools & Keyed DI
Tools & Keyed DI
How the agent gets hands — and how every action stays sandboxed and governed
Tools are the concrete actions an agent can take. Every single tool call passes through the same safety checkpoint before it runs, and file access is fenced to an explicit allow-list, so even a confused or manipulated agent cannot reach outside its sandbox.
Keyed DI Resolution Governed Invocation Output Compression & Spill
MCP
MCP — Model Context Protocol
The open standard for plugging in tools built by anyone, anywhere
MCP is a shared language for AI tools, so the harness can call tools built by other teams — and let other AI systems call tools built here — with no custom integration per tool. Every external tool is automatically screened for hidden or malicious instructions before the agent ever sees it.
Server — Expose Client — Consume Security Scanning
Orchestration
Agent Harness & Orchestration
The engine that turns one user message into a governed, observable agent turn
This is the assembly line every request runs through: check it is safe, figure out which skill applies, build or reuse the right agent, run it, and record exactly what happened. New capabilities get added by writing a skill or a tool, not by changing this pipeline.
Pipeline Behaviors Agent Caching Loop Guards
Observability
Observability & Safety
See inside every agent turn, and stop it when it goes wrong
Every AI call and tool use is recorded in a searchable timeline. On top sits a stack of independent safety checks — filtering harmful content, requiring human sign-off on risky actions, and a tamper-evident audit log nobody can quietly edit after the fact.
Distributed Tracing Graded Autonomy & Escalation Meta-Harness Self-Improvement
RAG Pipeline
RAG Pipeline
Grounding agent answers in your real documents, not just training data
Retrieval-Augmented Generation is how the agent answers questions about your own documents accurately — it finds the genuinely relevant passages first, then has the AI write an answer based on what it found, with citations back to the source.
Hybrid Retrieval CRAG Quality Gate Complexity Routing Retrieval Backend
Knowledge Graph
Knowledge Graph
Structured, persistent memory of entities and relationships, not just text chunks
Beyond searching documents, the harness can build and remember a map of entities and how they relate, so an agent's understanding compounds across sessions instead of starting fresh every time — with old or irrelevant facts fading out automatically.
